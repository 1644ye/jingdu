# 依赖与来源

这是新开发项目，没有直接复制 Anx Reader、FrogReader、Legado、Readest 或 Librera 源码。

| 依赖 | 用途 | 许可证 / 来源 |
| --- | --- | --- |
| Kotlin 标准库 | 运行时 | Apache-2.0；https://github.com/JetBrains/kotlin |
| Gson 2.11.0 | JSON AST及严格流式读取 | Apache-2.0；https://github.com/google/gson |
| JUnit 4.13.2 | 仅测试 | EPL-1.0；https://github.com/junit-team/junit4 |
| Gradle Wrapper | 开发构建 | Apache-2.0；https://github.com/gradle/gradle |

诗歌示例为用户提供的李白《静夜思》及附带译文；小说示例为用户提供的原创示例《山城来信》。测试长篇数据由本项目脚本生成。示例均明确标记，未抓取网络书籍或封面。
