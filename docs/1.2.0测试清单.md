# 1.2.0 开发与统一测试

日期：2026-11-01。

## 本轮开发

- 下载改为 noBackupFilesDir 中的 AtomicFile 持久任务队列，由 JobScheduler 后台任务执行，页面关闭不终止下载。
- 支持等待、下载中、暂停、失败、取消和完成状态，恢复/重试保留原任务的仓库、账号、提交与临时文件。服务器支持 Range 时续传；返回完整200响应时重下，不拼接重复内容。
- 书源账号或仓库变更时取消旧连接任务；失败连接不切换。任务文件不保存访问令牌。
- 远端标签只读、个人标签独立保存与编辑；更新正文和备份恢复保留个人标签，包括与来源同名的个人标签。搜索继续使用标签并集。
- 刷新有效索引时核对已下载书籍是否仍在索引和远端目录中，标记源文件已移除，但保留本地正文和阅读记录。源重新出现时可恢复标记。
- 主应用返回路径保存到实例状态；GitHub 页面保存页面类别、目录、搜索与勾选。授权页重建后返回账号设置重新授权，不将设备授权凭据写入实例状态。

代码和测试代码编写完成后才启动统一测试。编译阶段没有执行测试。

## 自动测试范围

- 核心协议、定位、索引、进度向量、交付书籍解析。
- 完整 Android 回归，含原有阅读、导入、备份、分页与性能流程。
- 新增：磁盘任务重开、暂停/取消、模拟断网后保留片段、206续传及200重下、只入库一次。
- 新增：源/个人标签跨更新和备份恢复；源移除/恢复标记不删除本地书籍。
- 新增：GitHub 设置页和主应用返回路径在 Activity 重建后恢复。

自动下载测试使用固定 HTTP 响应，不写入实际 GitHub 仓库；真实服务器是否支持 Range 必须实机验证，不能把回退重下标为实际续传。

## 你需要执行的手机测试

入口：“更多 → GitHub 书库与进度同步”。先确认两套登录、书源 reading-library 和私有进度 reading-state；书源中应有唐诗、中文及英文基督山伯爵三本书。

| 顺序 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 1 | 覆盖安装，检查旧书架、进度、标签、笔记 | 原有数据保留 |
| 2 | 刷新书库，勾选两本小说下载，再返回书架 | 下载任务入口能看到状态，页面关闭不取消任务 |
| 3 | 下载中暂停、关闭再打开 App、继续 | 任务与已下载字节仍在；服务器支持时续传，不支持时重下 |
| 4 | 下载中断网，恢复网络后等待或手动重试 | 本地阅读正常，任务说明失败/等待原因；最终正文完整且只导入一次 |
| 5 | 取消未完成任务，随后重新选择下载 | 取消状态保留；重新下载能正常完成 |
| 6 | 有未完成任务时更换书源账号或仓库，再查看旧任务 | 保存新连接后旧任务取消，不用新账号继续下载旧任务 |
| 7 | 本书详情添加个人标签，编辑信息移除个人标签；刷新正文 | 来源标签只读，个人标签可改；更新后个人标签保留 |
| 8 | 在 GitHub 临时从 catalog.json 移除一本已下载书，再刷新 | 本地书架与详情显示源文件已移除，仍能阅读；还原索引后标记恢复 |
| 9 | 进入多级目录、进入书籍笔记页，旋转屏幕或重建页面后点 `<` | 返回原上一级，不直接丢失整条路径 |
| 10 | A 阅读并同步，B 下载同一本书并同步；随后反向操作 | 两方向均恢复到对应文字位置，不以页码作为依据 |
| 11 | A、B 离线分别阅读同一本书，再联网同步并选择位置 | 保留两条候选；选择后其他设备采用结果，同一冲突不反复出现 |
| 12 | 恢复旧备份、撤销授权后重登、更换同步仓库 | 恢复/更换后先暂停同步，不自动覆盖其他设备的新进度；重登后可恢复使用 |

源索引的临时编辑由你在 GitHub 上操作，App 不修改书源。正式书库变更测试后需还原该条索引。

Android“强行停止”会阻止后台任务，应重新打开 App 后恢复；本版不绕过系统限制，不承诺退出瞬间或重启手机后立即继续。

## 不属于本轮开发范围

App 修改远端书源、多书源同时聚合、笔记/书签/个人标签跨设备同步、保存客户端密钥实现令牌静默续期。令牌过期仍需重新登录。
