# 1.4.0 书架与辅助阅读

## 交付行为

首页点选或横滑只更新当前书籍数据，保留页面、列表、适配器及底部标签。切换动画为180毫秒的小幅平移和透明度变化；快速反向切换取消旧动画并从当前位置衔接。各书架保留本次页面会话中的滚动位置，搜索和筛选保留。

底部“＋”可直接新建书架。“加入书架”的选择列表始终提供“＋ 新建书架并加入”，即使已有书架也可继续创建，并将所选书籍加入。管理入口仍在更多菜单。

诗集阅读工具栏的“辅助”分别设置拼音、逐行译文、逐行注释、创作背景、全诗译文、赏析。四种方式是隐藏、小字、正文大小、点击链接浮现。链接只弹出完整文本，关闭后保留阅读位置；设置立即写入，支持原有单书／全局阅读设置范围。明确选择隐藏后，点击原文不会强制展开；旧设置沿用之前的点击展开行为。

阅读目录及详情目录显示“阅读中／已读”。首次保存该篇位置记为阅读中，显示最后一页或滚动看到末行／末段末尾后记为已读。已读标记保留，跳过的章节不按位置批量标记。完整与所选备份保存该书的标记；删除书籍同时删除。GitHub 同步仍为书籍进度与状态，篇章历史不跨设备单独合并。

诗集模板包含六类辅助内容的实际填写示例；唐诗319篇、1613行补入带调拼音，每首至少一项词语注释及阅读背景。背景根据诗题、原序和正文编写，不伪造写作年份。拼音有常见多音字校正，未完成逐字人工校勘。稳定 ID 保留，四处缺字占位改为媕、窅、箓、菑，修正个别作者姓名。两部小说正文未修改。
