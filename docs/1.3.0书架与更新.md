# 1.3.0 书架、首页同步与软件更新

日期：2026-11-01。

## 已实现的操作

- “更多 → 自定义书架”：新建、改名、调整顺序、删除书架，也可重命名首页。沿用原有分组和归属，一本书可加入多个书架；删除书架保留书籍。
- 首页底部显示首页和自定义书架，点击名称或在正文书籍列表区域左右滑动切换。底部名称栏支持横向滚动，当前书架突出显示，并记住上次选择。
- 书籍详情可切换“在首页显示／从首页隐藏”；“更多 → 书架管理 → 批量操作”也支持批量设置。隐藏只影响首页，自定义书架和管理页仍能找到该书。新导入书籍默认显示在首页。
- 首页保留继续阅读、立即同步、搜索、筛选排序、书籍列表及底部书架。列表／网格切换移至“更多”。
- “立即同步”使用原有双向进度同步服务，先等待本地阅读位置写入。执行时显示“同步中…”，失败显示真实原因并恢复按钮；成功后刷新书架。未配置时提示先连接和保存进度账号与仓库。
- 首页名称、书架顺序和首页显示偏好保存在数据库元数据中，随完整备份恢复；所选备份只包含所选书籍的首页显示偏好。当前书架、列表／网格和软件更新开关属于本机偏好。

## 软件更新

入口：“更多 → 软件更新”。更新源固定为公开项目 `1644ye/jingdu` 的 GitHub Releases，与可手动更换的书源和同步仓库分别管理，不向这两个仓库写入文件，也不使用书源登录令牌下载软件。

- 默认开启每天一次的自动检查，在打开主应用时执行；可手动检查。
- 可开启自动下载，默认关闭；开启后使用当前网络。手动检查发现新版后也可点击下载。
- Android DownloadManager 下载到本应用外部文件目录，支持系统通知、状态查询和取消清理。App 关闭后由系统继续调度。
- 安装前核对包名、递增的 versionCode，以及与当前应用相同的签名证书。不会降级覆盖或安装其他应用。
- 需要更新 APK 下载完成后，用户在系统设置允许静读安装应用，并在系统安装器确认。关闭授权或取消安装不会影响书库。
- 自动更新服务需要仓库已有符合下述约定的正式 Release。没有发布包时显示“尚未发布可下载版本”；网络或 GitHub 限流错误显示检查失败，不误报为最新版。

### 后续发布约定

1. 每次增加 `app/build.gradle.kts` 中的 versionCode 和三段式 versionName，例如 `1.3.1`。
2. 使用与已有 APK 相同的签名构建；当前为开发签名。更换签名后不能覆盖旧安装。
3. 在 `1644ye/jingdu` 发布正式 Release，标签如 `v1.3.1`；不可标记为 draft 或 prerelease。
4. 附加一个 `QuietReader-1.3.1.apk`。可以保留源码等其他附件，整个 Release 只附加一个 APK，避免安装包选择不明。检查器也兼容此前的 `QuietReader-版本-debug.apk` 命名。
5. 更新说明使用 Release 正文。APK 下载链接必须位于该项目的 HTTPS Releases 下载目录。

发布使用 `:app:assembleRelease`，产物为非调试的 Release 构建，沿用现有开发签名；开发签名私钥不入库。1.3.0 的发布页为 https://github.com/1644ye/jingdu/releases/tag/v1.3.0 。要实际验证从已安装的 1.3.0 下载并升级，必须再发布一个更高版本的同签名 APK。发布不修改用户的书源或进度仓库。

## 手机验收清单

| 操作 | 预期 |
| --- | --- |
| 覆盖安装 1.3.0 | 旧书籍、原有分组归属、阅读位置和笔记保留 |
| 更多中新建“诗集”“小说”，改名、上移／下移 | 底部名称和顺序对应变化，重启后保留 |
| 书籍详情加入两个书架，底部点击及左右滑动切换 | 两个书架均可见此书，竖向滚动不会切换书架 |
| 单书从首页隐藏；管理页选多本批量隐藏和恢复 | 首页按选择显示，管理页和所属书架仍能找到隐藏的书 |
| 从更多切换列表／网格 | 显示方式立即变化，首页没有独立的显示切换按钮 |
| 阅读后返回，在继续阅读旁点击立即同步 | 有执行中反馈；配置正确时同步，配置缺失、断网等情况显示原因并可重试 |
| 两台已授权设备交替阅读并立即同步 | 双向恢复对应文字位置，离线并发仍走原有冲突选择流程 |
| 完整／部分 ZIP 备份后恢复 | 首页名称、相关书架与首页显示选择保留；恢复仍是整体替换 |
| 更多 → 软件更新，检查并切换自动检查／下载开关 | 可看到当前版本、检查结果；开关重开后保留 |
| 已发布更高同签名版本时下载；中途断网后恢复 | 展示下载／等待／失败等状态，系统通知可见，失败可以重试 |
| 安装新版本，或在系统安装器取消 | 成功安装后原有数据保留；取消时旧版仍可用 |
