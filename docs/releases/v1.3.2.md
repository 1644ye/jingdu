# 静读 1.3.2

- GitHub 登录新增自动续期，分别加密保存书源与同步账号的刷新凭据。
- 目录、下载和同步在令牌临近到期时刷新；401 最多刷新重试一次，断点下载保留片段。
- 并发请求复用刷新结果，续期不改变仓库或暂停同步；网络失败可重试，凭据被撤销或刷新令牌到期时明确提示重新登录。
- 覆盖安装保留书库、账号与仓库，继续使用原签名。

**升级后，请分别用原账号重新登录书源和同步角色一次。** 旧版没有保存刷新令牌，重新登录才能启用自动续期。账号设置会显示“已启用自动续期”；仓库选择保留，进度角色重新登录后需重新确认开启同步。

下载 `QuietReader-1.3.2.apk` 直接覆盖安装。支持 Android 8.0 及以上，为非调试 Release 包。

续期测试使用模拟响应与可控时钟；真实账户跨 8 小时的联网使用仍请按 `docs/1.3.2自动续期.md` 核对。
