# 静读 1.4.0

- 首页切换书架保留列表与底部标签，使用短距离平移动画，连续横滑时取消上一段动画并衔接。
- 首页底部增加“＋”；已有书架时，“加入书架”仍可新建并直接加入所选书籍。
- 阅读诗集新增“辅助”入口。拼音、逐行译文、注释、创作背景、全诗译文和赏析分别支持隐藏、小字、正文大小、点击链接弹出。随时恢复只显示原文。
- 书籍详情和阅读目录显示篇章“阅读中／已读”。翻到最后一页，或滚动看到末行／末段结尾后记为已读；跳过章节不会批量标为已读。记录随本地备份保存，当前 GitHub 进度同步范围保持为书籍位置和状态。
- 诗集模板补齐全部辅助字段和实际示例；《唐诗三百首》319 篇补充 1613 行带调拼音、每首词语注释和阅读背景，修正旧文本的缺字占位。两部《基督山伯爵》保留原文。

下载 `QuietReader-1.4.0.apk` 覆盖安装，Android 8.0 及以上。沿用原包名与签名，保留本地书籍、账号、仓库及设置。

**已有唐诗正文需另行更新。** 在书源索引刷新，检查当前目录正文更新，再下载／更新《唐诗三百首》；本地导入请选择同 ID 更新。只安装 APK 不会替换已下载的书籍。模板与最新版唐诗文件见项目 README 的直接下载链接。

## 手机验收

1. 在多个书架间点选、快速连续左右滑，观察是否闪白、页面跳动或丢失筛选；检查各书架的滚动位置。
2. 已有一个书架后，从底部“＋”和“加入书架 → 新建书架并加入”继续创建，确认书籍归属。
3. 更新唐诗后，在“辅助”里分别切换四种显示方式；点注释／背景链接，关闭后确认阅读位置；退出再进入确认设置保留。
4. 读完一首／一章、跳过一篇再打开后面的篇章，核对两处目录的已读／阅读中／未读区别；备份恢复后再看标记。
5. 覆盖升级后确认原账号和仓库保留，并核对登录自动续期、下载和立即同步。
