## 拼音仍未出现时

1. 阅读唐诗，点工具栏“辅助”，查看“拼音”后的内容数量。
2. 如果显示“本篇未提供”，本地仍是缺少拼音的正文。进入 GitHub 书源索引刷新、检查正文更新，再下载／更新唐诗；本地导入请选择同 ID 的“更新内容”。安装新版 APK 不会自动替换已下载正文。
3. 有拼音时选择“小字显示”或“正文大小”；选择“点击链接浮现”后，点正文里的“〔拼音〕”查看全文。
4. “更多 → 全局阅读设置”只作用于未单独设置的书籍。已有单书设置时，直接在该书的“辅助”中调整，或在阅读设置中恢复本书为全局设置。

唐诗交付版含319篇、1613行拼音及词语注释和背景；全诗译文、逐行译文、赏析是否显示，取决于正文是否实际提供。两部小说正文保持不变。
