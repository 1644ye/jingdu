# 静读 1.3.0

## 本次更新

- 自定义书架：新建、改名、排序、删除，底部点选或左右滑动切换；沿用已有分组归属。
- 首页显示选择：单书或批量隐藏／恢复，隐藏书籍仍可在所属书架和书架管理中找到。
- 首页布局调整：列表／网格切换移至“更多”，继续阅读旁新增“立即同步”，提供执行状态和失败反馈。
- 软件更新：GitHub Releases 自动检查、可选自动下载、安装包校验及系统确认安装。
- 包含此前的 GitHub 只读书源、手动账号／仓库切换、持久下载队列、个人标签与双向阅读进度同步。

## 安装

下载附件 `QuietReader-1.3.0.apk`，支持 Android 8.0 及以上。此 APK 为非调试的 Release 构建，沿用之前交付版本的开发签名，可覆盖安装并保留书库；不要先卸载旧版。开发签名未随源码公开。

软件更新入口为“更多 → 软件更新”。后续同签名、更高版本的正式 Release 可由 App 检查和下载，安装仍需用户在系统页面确认。

## 验证与边界

同版本功能代码已通过 42 项核心测试、63 项 Android 回归测试，最终相关 6 项复测通过。Release 构建和单独验收记录见仓库 `docs/1.3.0书架与更新.md`。真实双设备同步、手机后台调度及从未来更高版本 Release 下载升级仍需实机验收。
