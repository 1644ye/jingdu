# 静读 1.3.1

- 首次使用不预填个人账号、书源或进度仓库。连接、浏览和下载书源前需要登录自己的 GitHub 账号，再选择可访问的仓库。
- 覆盖升级保留本机已登录账号、已保存仓库、书库与阅读记录。同账号重新授权继续保留仓库选择。
- 成功切换到不同账号后，清空该角色的旧仓库选择与验证状态；书源缓存和旧下载任务不再沿用，另一个角色的账号与本地书籍保留。更换进度账号后暂停同步，重新确认仓库后开启。
- 清理公开文档、测试记录和 Git 历史中的个人配置、作者联系方式及构建机器路径；发行包不包含预置访问令牌。

下载 `QuietReader-1.3.1.apk`，直接覆盖安装，勿先卸载旧版。此包为非调试 Release 构建，沿用旧版本签名，支持 Android 8.0 及以上。

公开项目的软件更新地址和 GitHub 登录应用的公开 Client ID 继续保留；它们不代表使用者身份。使用者的令牌仅在本人授权后加密保存在本机。

历史已重写，已有开发克隆应重新克隆，避免把旧历史重新推回。GitHub 的旧提交缓存及第三方已取得的副本不随 Git 推送自动清除。
