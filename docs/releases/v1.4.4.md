# 静读 1.4.4

日期：2026-11-05。

修复连续回滑时前文加载慢、手指按住期间等待正文及出现大片空白的问题。

## 修改

- 前文触发距离从距顶约 80dp 提前到一个阅读视口；进入非起始篇章或长章中段时主动预读前一片段。后文同样提前一个视口准备。
- 拖动期间可以显示已准备好的正文，不再一律等松手后稳定 120 毫秒。在原生布局过程中，根据实际片段高度补偿位置，并包含插入后、布局前新到达的拖动距离。
- 如果松手惯性恰好在插入与布局之间开始，延至完成位置补偿后再启动；已经运行的惯性动画仍等待稳定后再改动坐标，避免旧动画把页面拉回旧位置。
- 短篇不再固定只容纳三个片段，按内容高度补足约三屏的有限预读空间，最多八片段；长片仍保持较小窗口。只补足预读空间，窗口满后不以加载回调接力回收推进。
- 保留按滚动方向加载及不回收可见片段的规则；加载和重新测量不修改持久阅读锚点的身份。

## 手机复测

1. 覆盖安装，打开此前出现等待的书籍，连续向上回看；按住手指缓慢拖动，确认前文能在松手前接上。
2. 在多首短诗、章节交界和长章节中反复上下滑动，停手后应自然停止，当前文字不应跳往后方。
3. 从目录跳到中间篇章后立即回滑；切换拼音、字号和横竖屏，再返回继续阅读，核对位置。

本次复测需使用实际出问题的书籍与手机；模拟器中的坐标与等待测试范围见下方验证记录。
