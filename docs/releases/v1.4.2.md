# 静读 1.4.2

日期：2026-11-05。

修复连续滚动一段时间后，无后续手势仍自行向远处推进的问题。

连续阅读使用最多三个正文片段的窗口。此前，短篇末尾用于恢复位置的留白可能让“接近底部”条件持续成立，加载完成回调又启动下一次加载，导致一次滑动后连续回收、前进。现在回调仅补齐尚未填满的窗口，窗口填满后继续加载由后续滚动事件触发。

保留短诗位置恢复、正常手动上下滚动、小说和诗集阅读，以及原有拼音和辅助内容显示。覆盖安装保留书籍、登录、仓库、设置和阅读记录。

## 验证

- 旧版复现：60 个短章组成的测试书，一次滚动后不再操作，窗口末端从索引 2 自动推进到 5，回归断言失败。
- 修复后同一断言通过；非调试 Release 上 9 项阅读设备测试通过（26.415 秒），覆盖短章回调接力、长章窗口与惯性、六类辅助显示及短诗位置恢复。
- Release APK、测试 APK 构建成功；Release Lint 0 错误、28 警告，沿用现有分析器配置。
- 未把旧版 96 项全量记录算作本次执行；本轮改动集中在连续滚动窗口加载。

## 手机复测

1. 在原安装上覆盖安装 1.4.2，打开此前出现问题的同一本书。
2. 使用连续滚动，上下滑动一段时间，穿过多首短诗或多个章节；停手并等待正常惯性结束，页面应停止前进。
3. 反向回看、切换拼音显示，再返回首页重新进入，核对文字位置。
4. 也可检查“上一页／下一页”按钮及目录跳转；它们应保持可用。

如仍跳跃，记录书名、连续滚动或分页模式、是否停手后仍持续移动，以及大致跨过的篇数，以区分其他触发路径。
