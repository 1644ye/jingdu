## 待验证

- 用户注册的两套 GitHub App 的实际设备授权、安装范围和读写权限。
- 实际私有仓库索引读取、正文下载、远端进度写入、授权过期与重新登录。
- 两台实际设备的顺序阅读、离线并发、正文版本变化和账号切换。

当前 GitHub 连接器读取 reading-library 和 reading-state 均返回 404。这不能证明仓库不存在；私有仓库未授权给该连接器时也会如此。连接器的授权与手机 App 的两套授权相互独立。

真实登录需要用户在 GitHub 浏览器页面完成授权，不能以公开 Client ID、编译成功或本地测试替代。未完成这些步骤前，1.1.0 仅作为待实际联网验收的 debug 版本交付。
