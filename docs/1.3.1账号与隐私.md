# 1.3.1 账号初始化与隐私清理

## 行为

新安装的书源与进度连接均为空，登录后只将当前授权账号填为候选所有者，仓库仍需使用者选择。即使是公开书源，也需要本人登录后才能连接和下载。书源仍为只读，进度仍要求独立私有仓库。

升级不重置 `github-connections`、Keystore 密钥、正文数据库、下载记录或进度日志。已保存账号与仓库直接沿用；同账号重新授权保留仓库。成功更换到不同账号时仅清空该角色的仓库配置与验证状态，并阻止继续沿用原书源缓存和任务；同步账号更换后先暂停同步，另一个角色的账号、本地书籍及阅读记录保留。主动退出会移除该角色的账号和仓库配置。

首次登录、切换浏览器账号及 GitHub App 安装要求见 `GitHub登录配置.md`。保留公开软件更新地址和登录应用的公开 Client ID；不在 APK 中预置个人账号、个人书源、个人进度仓库或访问令牌。

## 公开项目

当前文件、历史文件快照及历史提交作者／提交者信息执行去标识化；测试输出只保留相对项目路径。公开 Release 使用清理后的 APK 与源码。旧发行包含个人默认值，撤下旧 Release，使用新版替代。原始个人书籍、临时上传克隆和本机签名不进入源码归档。

用户已明确允许重写历史。使用推送前读取的远端提交作为 lease，不覆盖未知并发修改。重写后旧克隆需重新克隆。GitHub 可能保留无引用的旧提交缓存；Git 推送不能撤回其他人已取得的副本，平台缓存彻底移除可能需要 GitHub Support。

## 验证

全部功能和测试代码完成后统一验证：新安装无默认连接、已有设置跨重开保留、同账号重新授权、不同账号清空仓库且角色隔离、同步暂停、主动退出、匿名后台下载拒绝，以及首次界面的登录引导。最终测试记录保存在 `artifacts/verification/1.3.1/`。

核心 42 项沿用未变代码的通过缓存；API 36 全套 Android 回归 71 项通过（67.222 秒）。debug、测试包和 Release 构建成功，Release Lint 0 错误／28 警告。真实 GitHub 授权仍需在设备浏览器用目标账号完成，自动测试使用虚构账号和本机加密令牌夹具，不声称已经完成其他用户的真实授权。

最终非调试 Release 包覆盖安装成功（versionCode 10），17 项相关测试通过（6.136 秒）。已扫描 APK 解压条目，未发现个人书源／进度默认值、邮箱或本机路径，保留项只有公开项目更新地址及登录应用标识；APK 的版本控制元数据已指向清理后的历史。源码历史对象在独立仓库中逐项扫描后才接入主分支，当前文件树与已测试代码保持一致。
