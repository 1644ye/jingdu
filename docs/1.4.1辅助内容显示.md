# 1.4.1 辅助内容显示

## 问题与修正

在连续滚动阅读短诗时，切换拼音等辅助内容会重新布局；旧实现可能在新内容布局前恢复滚动位置，且短诗末尾的可滚动范围不足。向前补入相邻诗作时，原位恢复被截断，页面可能回到前一首；辅助内容设置页随后也按前一首统计。

现在等待原生视图完成布局后恢复原文位置，在末尾保留定位所需空间，并让后续内容加载按真实内容末尾判断。当前篇章及原文位置在切换显示方式、补入前篇和末篇定位时保持。

另两处修正：全局阅读设置改用与阅读页一致的六类、四种显示方式，直接读取实际模式；正文缺少字段时不再静默无反馈。“辅助”页显示当前篇名及各类非空内容数量，正文提供缺项说明，显示偏好保留。所有辅助弹窗使用阅读配色。

确认解析和保存没有丢弃已有辅助字段。唐诗原交付版含319篇、1613行拼音，每首有词语注释和背景；未补全逐行译文、全诗译文及赏析。旧版本已下载或已导入的正文不会随APK更新而自动替换，须另行更新内容。两部小说保持原文。
