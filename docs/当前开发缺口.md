## 1.4.0 新增能力

书架切换保留页面和列表实例，新增书架入口持续可用；诗集六类辅助内容分别支持隐藏、小字、正文大小和链接弹窗；两处目录显示篇章阅读中／已读。篇章标记进入本地备份，目前不作为独立历史记录跨设备合并。唐诗319篇补入实际拼音、词语注释和阅读背景；拼音有常见异读校正，尚未完成逐字人工校勘。两部小说保留原文。手机验收步骤见 [1.4.0 发布说明](releases/v1.4.0.md)。

## 1.3.0 新增能力

自定义底部书架、横滑切换、首页显示选择、更多菜单中的列表切换、首页立即同步及 GitHub Releases 软件更新已实现。书架数据和交互通过模拟器回归；软件更新的 Release 筛选和安装包校验有自动测试。实际下载、系统覆盖升级及双设备同步仍待联网与手机验收，见 `1.3.0书架与更新.md`。当前开发网络查询 Release 遇到 GitHub API 403 限流，没有据此判断远端是否已发布版本。

## 1.2.0 已补齐的实现

- 下载：任务与临时片段持久化、后台执行、暂停/恢复/取消；服务器支持Range时续传，否则从头重下。受Android后台调度与强行停止限制。
- 来源标签：只读来源标签与可编辑个人标签分别显示和保存，备份保留两者；搜索使用并集。
- 远端删除：索引刷新时核对已下载书籍的来源，显示“源文件已移除”，保留本地书籍；恢复来源后可清除标记。
- 导航：保存主应用返回路径以及GitHub页面、目录、搜索和勾选状态。授权页重建后返回账号设置重新授权。

本轮代码与配套测试编写后统一测试；实际结果和操作清单见 1.2.0测试清单.md。

## 本轮明确不包含的能力

- App 内修改 GitHub 书源：按用户要求禁止。
- 书签、笔记、划线、个人标签与配色跨设备同步：当前仅同步阅读位置与阅读状态。
- 多书源同时聚合：当前一次使用一个书源，允许手动更换。
- 1.3.2 已实现设备授权令牌自动续期，不在 APK 保存客户端密钥；旧版登录需重新授权一次，真实账户跨到期时间的联网使用仍待手机核对。
