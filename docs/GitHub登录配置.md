# GitHub 登录与仓库配置

首次使用不预填账号或仓库。现有安装升级时保留本机已登录账号、令牌和已保存仓库；书库与阅读记录保留。

## 个人使用

1. 打开“更多 → GitHub 书库与进度同步 → 书源账号与仓库设置”。
2. 点击“登录 / 更换账号”，在浏览器登录自己的 GitHub 账号并完成设备码授权。浏览器已登录其他账号时，请先切换到目标账号。
3. 从已授权仓库选择自己的书源，或填写可访问的仓库所有者和仓库名，再连接并保存。即使是公开书源，也需要先登录。
4. 在仓库根目录上传书籍 JSON 和 catalog.json；App 只读书源，不创建或修改远端内容。索引可用 tools/generate_catalog.py 生成。
5. 在“进度账号与仓库设置”独立登录并选择自己的私有进度仓库。书源与进度必须使用不同仓库。
6. 同步连接确认后，在“阅读进度同步”启用同步；账号或同步仓库更换后需重新确认开启。

成功更换到不同账号后，旧角色的仓库选择和验证状态会清空；书源缓存和旧下载任务也会停止沿用。另一个角色的登录不受影响，本地已下载书籍与阅读记录不删除。同账号重新授权保留原仓库选择。主动退出该角色会移除其登录和仓库配置。

## 登录应用的配置

书源与同步使用两套 GitHub App：书源 Contents 只读；同步 Contents 读写。启用 Device Flow，并安装到各自需要访问的仓库。面向其他使用者分发时，应允许他们将 GitHub App 安装到自己的账号或组织仓库。

应用中公开 Client ID 是登录应用标识，不是使用者账号或访问令牌。APK 不包含 Client Secret、私钥或预置访问令牌；令牌仅在用户授权后由本机 Keystore 加密保存，完整书库备份不导出令牌。

## 自动续期（1.3.2）

分别用原账号重新登录一次，获取并加密保存刷新凭据。看到“已启用自动续期”后，书源和进度请求会自动刷新令牌；续期保留原仓库与同步开关。不自动过期令牌继续支持。旧版登录没有刷新凭据、授权撤销或刷新令牌过期时，需要重新登录。同账号重登保留仓库，进度角色重登后重新确认开启同步。
